Нативный порт быстрого и легковесного веб-браузера [NetSurf](https://www.netsurf-browser.org/) для платформы Homebrew консоли Nintendo Switch.

---

## ✨ Возможности

- **Быстрый и лёгкий**: Собственный движок вёрстки NetSurf, оптимизированный под минимальное потребление оперативной памяти и быстрый рендеринг веб-страниц.
- **Удобное управление**:
  - Полная поддержка контроллеров Joy-Con и Pro Controller (плавный виртуальный курсор мыши и скроллинг стиками).
  - Поддержка сенсорного экрана (нажатие для клика, свайпы для прокрутки).
  - Интеграция системной экранной клавиатуры Switch (`swkbd`) для ввода адресов сайтов и заполнения форм.
- **Поддержка стандартов**: CSS 2.1, парсинг HTML5, защищённые соединения HTTPS/TLS через mbedTLS и libcurl, декодирование изображений (PNG, JPEG, WebP, GIF, BMP).
- **Чистый открытый код**: Собрано исключительно с помощью открытого набора инструментов [devkitPro](https://devkitpro.org/) / `libnx` без использования проприетарного или утёкшего кода.

## 🎮 Управление

| Кнопка | Действие |
| :--- | :--- |
| **Левый стик** | Перемещение виртуального курсора мыши |
| **Правый стик / D-Pad** | Прокрутка страницы (Вверх / Вниз / Влево / Вправо) |
| **(A)** | Левый клик мыши / Переход по ссылке |
| **(B)** | Назад в истории браузера |
| **(X)** | Фокус на адресной строке (URL) |
| **(Y)** | Открыть экранную клавиатуру Switch (`swkbd`) |
| **(L) / (R)** | Предыдущая / Следующая страница |
| **(ZL)** | Правый клик мыши / Контекстное меню |
| **Сенсорный экран** | Нажатие — клик, перетаскивание — прокрутка |
| **(+) Plus** | Выход из браузера в Homebrew Menu |

## 📥 Установка

1. Скачайте последнюю версию со страницы [Releases](https://github.com/Wertko29/NetSurf-NX/releases).
2. Распакуйте архив и скопируйте файл `NetSurf.nro` в папку `switch/NetSurf/` на вашей карте памяти:
   ```text
   sdmc:/switch/NetSurf/NetSurf.nro
   ```
3. Вставьте карту памяти в консоль и запустите **Homebrew Menu** (`hbmenu`).
4. Выберите **NetSurf** и запустите его.

> [!TIP]
> Рекомендуется запускать Homebrew Menu в режиме полного доступа к памяти (Title Redirection / зажав кнопку `[R]` при запуске любой установленной игры), чтобы у браузера было максимум оперативной памяти для тяжёлых страниц.

## 🛠️ Сборка из исходников

### Требования
- Установленный [devkitPro](https://devkitpro.org/) с тулчейном `devkitA64` и библиотекой `libnx`.
- Необходимые портированные библиотеки для Switch:
  ```bash
  dkp-pacman -S switch-sdl2 switch-sdl2_image switch-freetype switch-libpng switch-libjpeg-turbo switch-curl switch-mbedtls
  ```

### Инструкция по сборке
```bash
git clone https://github.com/Wertko29/NetSurf-NX.git
cd NetSurf-NX
./build_netsurf.sh
```
